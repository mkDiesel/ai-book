# Quickstart

This guide explains how to set up the Docusaurus site locally.

## Prerequisites

- Node.js (version 16.14 or later)
- npm or yarn

## Installation

1.  **Clone the repository**:
    ```bash
    git clone <repository-url>
    cd <repository-directory>/my-website
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```
    or
    ```bash
    yarn install
    ```

## Running the development server

1.  **Start the server**:
    ```bash
    npm start
    ```
    or
    ```bash
    yarn start
    ```

2.  **Open the site**:
    Open your browser and navigate to `http://localhost:3000`. The site will automatically reload when you make changes to the source files.

## Building the site

To build a static version of the site for production, run:
```bash
npm run build
```
or
```bash
yarn build
```
The built files will be in the `my-website/build` directory.
