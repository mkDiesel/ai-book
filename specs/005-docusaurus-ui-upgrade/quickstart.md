# Quickstart

This document provides instructions on how to set up the development environment and run the Docusaurus site.

## Prerequisites

- Node.js (v18 or later)
- npm or yarn

## Setup

1.  **Navigate to the website directory**:
    ```bash
    cd my-website
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```
    or
    ```bash
    yarn install
    ```

## Running the site

1.  **Start the development server**:
    ```bash
    npm start
    ```
    or
    ```bash
    yarn start
    ```

2.  **Open the site in your browser**:
    The site will be available at `http://localhost:3000`.
